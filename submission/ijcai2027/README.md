# IJCAI 2027 Submission Workspace

`template/` contains the unmodified official IJCAI 2027 author kit downloaded
from <https://www.ijcai.org/authors_kit>.

The WACV source remains frozen under `submission/wacv2027/`. The IJCAI paper
will be authored in a separate `paper/` directory after the result provenance
audit identifies which numerical artifacts are valid. This prevents accidental
copying of pending, inconsistent, or manually transcribed WACV table values.

Revision governance is in `docs/ijcai2027/`.
